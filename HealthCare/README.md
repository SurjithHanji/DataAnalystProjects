# 🏥 Healthcare Data Analysis Project

## 📌 Project Overview
This project focuses on analyzing healthcare (hospital) data using SQL to extract meaningful insights related to patient trends, hospital performance, and medical expenses.  

The goal is to simulate real-world healthcare analytics where data is used to improve operational efficiency, patient care, and decision-making.

---

## 🎯 Objectives
- Analyze patient and hospital data
- Identify trends in patient admissions and treatments
- Evaluate hospital and departmental performance
- Understand medical cost patterns
- Generate insights for better healthcare management

---

## 🛠️ Tech Stack
- **Database:** MySQL  
- **Query Language:** SQL  
- **Tools:** MySQL Workbench / SQL Editor  
- **Visualization (Optional):** Excel / Power BI  

---

## 📂 Dataset Description
The dataset includes:
- Patient details  
- Hospital information  
- Doctor data  
- Admission & discharge records  
- Medical expenses  

---

## 📊 Key Analysis Performed

### 🔹 Patient Analysis
- Total number of patients  
- Average patient stay duration  
- Patient distribution across hospitals  

### 🔹 Hospital Performance
- Number of patients per hospital  
- Doctor availability  
- Department-wise performance  

### 🔹 Cost Analysis
- Total and average medical expenses  
- Monthly expenditure trends  
- High-cost treatments identification  

### 🔹 SQL Concepts Used
- Joins (INNER, LEFT, RIGHT)  
- Aggregate Functions (SUM, AVG, COUNT)  
- GROUP BY, ORDER BY  
- Subqueries  
- Date Functions  

---

## 📈 Sample Insights
- Identified hospitals with highest patient inflow  
- Analyzed departments with maximum workload  
- Found trends in medical expenses over time  
- Detected inefficiencies in hospital resource usage
