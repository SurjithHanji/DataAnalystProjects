# 🛒 Blinkit Data Analysis Project

## 📌 Project Overview
This project focuses on analyzing sales and operational data of Blinkit, a quick-commerce grocery delivery platform. The analysis aims to uncover insights related to sales performance, customer behavior, and product trends using data analysis and visualization techniques.

Blinkit (formerly Grofers) is a leading quick-commerce platform that delivers groceries and essentials within minutes, leveraging data analytics for demand forecasting and operations. :contentReference[oaicite:0]{index=0}

---

## 🎯 Objectives
- Analyze sales and product performance  
- Understand customer purchasing behavior  
- Identify top-performing products and outlets  
- Evaluate key business KPIs  
- Generate insights for better decision-making  

---

## 🛠️ Tech Stack
- **Programming:** Python (Pandas, NumPy)  
- **Database:** MySQL  
- **Query Language:** SQL  
- **Visualization:** Power BI / Excel  
- **Tools:** Jupyter Notebook, Git, GitHub  

---

## 📂 Project Workflow

### 1. Data Collection
- Imported Blinkit sales dataset (transactions, products, outlets)

### 2. Data Cleaning
- Handled missing values  
- Removed duplicates  
- Standardized columns  

### 3. Exploratory Data Analysis (EDA)
- Analyzed product categories and sales trends  
- Studied outlet performance  
- Identified customer preferences  

### 4. Feature Engineering
- Created metrics like:
  - Total sales  
  - Average sales per outlet  
  - Product category performance  

### 5. SQL Analysis
- Performed:
  - Joins  
  - Aggregations  
  - Filtering  
  - KPI extraction  

### 6. Data Visualization
- Built dashboards using Power BI / Excel  
- Visualized:
  - Sales trends  
  - Product distribution  
  - Outlet performance
